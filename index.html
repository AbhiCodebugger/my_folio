Behind the scenes

How this site is built

This site is itself a small production system. Content lives in PostgreSQL behind a Serverpod (Dart) API. On every push — and once a day — GitHub Actions wakes the API, pulls the content once, and pre-renders plain HTML with Jaspr. Visitors get a static page from a CDN and never wait on a server.

  • Static HTML pre-rendered with Jaspr — crawlable, instant, no runtime API calls.
  • Serverpod API with a read-only public surface; seeding is an operator-only command.
  • Neon serverless PostgreSQL with migrations applied on deploy.
  • CI fails closed: if content can’t be fetched, the last good deploy stays live.
